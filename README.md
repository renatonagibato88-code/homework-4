# Домашнее задание к работе 4

## Условие задачи

Чтобы открыть портал, необходимо зажечь три древних кристалла. Кристалл загорается, если переданная ему энергия (A, B, C) кратна трем. Портал откроется только если загорятся все три кристалла. Запишите условие для открытия портала.

## 1. Алгоритм и блок-схема

### Алгоритм

1. Начало
2. Ввести три целых числа A, B и C.
3. Проверить условие:
	• (A % 3 == 0) && (B % 3 == 0) && (C % 3 == 0)
4. Если условие истинно, вывести:
	• Портал открыт
5. Иначе вывести:
	• Портал не открывается
6. Конец

## 2. Реализация программы

```c
#include <stdio.h>

int main()
{
    int A, B, C;
    int condition;

    printf("Введите три целых числа A, B и C: ");
    scanf("%d %d %d", &A, &B, &C);

    condition = (A % 3 == 0) && (B % 3 == 0) && (C % 3 == 0);

    if (condition)
    {
        printf("Портал открыт\n");
    }
    else
    {
        printf("Портал не открывается\n");
    }

    return 0;
}

```
